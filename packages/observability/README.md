# Observability

Métricas mínimas por `tick_id`:

- eventos recebidos e filtrados;
- intenções agregadas;
- latência de memória e runtime;
- provider/modelo;
- tokens de entrada e saída;
- TTFT;
- tempo até primeiro áudio;
- custo estimado;
- deltas aceitos/rejeitados;
- erros de continuidade.

Métrica principal de coerência:

`CER = contradições narrativas / transições narrativas`
