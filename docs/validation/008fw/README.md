# 008FW — Carry executed horizontal momentum during small falls

The bounded-gravity response previously stopped horizontal motion after the departure frame. NOV now captures the actual swept horizontal displacement on that frame, divided by the bounded integration interval, as its airborne velocity. The captured magnitude is capped by the requested movement speed and the existing 13 m/s local maximum; the live scene continues to request at most 8 m/s. Collision on departure prevents momentum capture.

Subsequent airborne steps carry that velocity with no new input steering or horizontal acceleration. Both horizontal and vertical integration use the existing 0.1 second frame bound. Horizontal movement first samples finite canonical ground at intervals of at most 0.2 m and applies the existing traversability validator, including the capsule sweep, endpoint occupancy, water classification, map limits, maximum upward step and maximum drop. It then uses the physical capsule's swept move. A rejected drift or solid collision clears horizontal momentum while allowing gravity to continue at the safe position.

On landing, surviving horizontal velocity transfers back to the supported inertia response; its next step can brake and turn using the existing 008FT response. Relocation clears carried velocity. Disabling the feature retains the prior vertically falling behavior. This remains the conservative small-drop model, with split horizontal/vertical sweeps and existing passage restrictions; it does not add jumping or general airborne navigation.

The live scene updates camera heading, active terrain tiles and perceptual vegetation after actual horizontal flight movement. This matters when a fall crosses a tile boundary: the early gravity return previously could not change horizontal position. The 008FV visual still receives real support and keeps the fall posture even with horizontal speed. Animal approach diagnostics receive actual collision counts.

Gravity results and terrain_motion diagnostics report actual horizontal displacement speed, surviving carry speed and any blocked reason. Journey distance may include physical drift when telemetry is enabled. Flight creates no new navigation decision serial, completed learning action, reward or cognitive success observation.

Activation: LIVE_INFINITA_NOV_AIRBORNE_MOMENTUM=1 in the native renderer, or live_infinita/nov_airborne_momentum=true in the exported project.
