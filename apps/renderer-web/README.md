# Renderer Web

Projeta o World State em cena visual sem ser autoridade sobre o mundo.

## V0.x

- HTML/CSS para HUD e controles;
- PixiJS/WebGL para cenário 2D persistente;
- animações locais para idle;
- Browser Source no OBS;
- consumo incremental de deltas visuais.

A cena deve ser reconstruível a partir de estado, seeds, parâmetros e relações. Imagens pré-renderizadas podem existir como cache/asset opcional, nunca como fonte de verdade.
